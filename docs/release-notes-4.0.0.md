# CellArchive 4.0.0 更新说明

## 一句话

细胞档案（CellArchive）—— 本地运行的细胞培养管理工具，记录细胞株、传代、冻存和生长曲线，自动算 PD 与倍增时间。

## 安装（三步）

1. 解压到一个有写入权限的文件夹，例如 `D:\CellArchive` 或桌面
   （不要放在 `C:\Program Files`）
2. 双击 `CellArchive.exe`
3. 浏览器自动打开 <http://127.0.0.1:18600/>

首次运行如果提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**。

## 这个版本有什么

### 自定义标签与配色（新）

- 细胞株的「标签」是自由文本，填物种、细胞类型、项目代号、来源都行，不预设任何选项
- **同一标签 → 同一色系**：图表里一眼看出属于一组
- **不同标签 → 明显区分**：每个标签独占一段色相区间，不会撞色
- **颜色只由标签名决定**：新增或改名标签不会让已有标签变色
- 支持「批量标注标签」，一次给多株填写

### 冻存管理改进（新）

- 首页新增「待录入位置」卡片：列出在库但没填孔位的冻存管
- 冻存管页面的待录入数量常驻页头，任何页签都看得到
- 表格**整行点击即可编辑**，不用再找「编辑」按钮
- 9×9 冻存盒视图，点空孔位直接录入

### 生长曲线优化（新）

- 组内曲线的图例改为**按细胞株合并的胶囊标签**，自动换行，不再分页
- 已终止批次支持**全选**，不用一个个勾
- 增殖速率图的纵轴标签拆成两行，长细胞株名不再被截断

### 已有的核心功能

- **在养细胞**：首页四张卡片（在养细胞株 / 在养批次 / 需要传代 / 待录入位置）
- **传代记录**：自动计算单次 PD、累计 PD、PD/天、倍增时间
- **生长曲线**：支持标准化（2^ΔPD）后跨批次比较
- **生长曲线对比**：任选多株放到同一张图，按日期或按培养天数对齐
- **数据安全**：SQLite 单文件，一键备份/恢复，兼容旧版数据

## 升级说明

从旧版本升级：**只替换 `CellArchive.exe`**，保留 `data` 和 `backups` 文件夹。

数据库会自动补齐新增字段，旧数据不需要迁移。

> 如果你的旧版本叫 `CellTracker.exe`，同样只替换 exe 即可，数据目录结构没变。

## 已知限制

- 仅提供 Windows 64 位版本
- 程序未签名，首次运行需要点「仍要运行」
- 默认只允许本机访问；局域网共享需改 `config.json` 的 `host`
