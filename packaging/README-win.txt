细胞档案 CellArchive 4.0.0
细胞培养管理追踪（Windows 64 位）
============================================================

一、安装（三步）
------------------------------------------------------------
1. 把压缩包解压到一个【有写入权限】的文件夹
   例如：D:\CellArchive 或桌面
   注意：不要放在 C:\Program Files 下，否则程序无法创建数据文件

2. 双击 CellArchive.exe

3. 浏览器会自动打开 http://127.0.0.1:18600/
   如果没有自动打开，手动在浏览器地址栏输入上面的地址

   黑色的命令行窗口不要关闭 —— 关掉它服务就停了。


二、首次运行可能遇到的提示
------------------------------------------------------------
* 提示「Windows 已保护你的电脑」
  点「更多信息」→「仍要运行」即可。
  这是 Windows 对未签名程序的通用提示，不影响使用。

* 提示端口 18600 已被占用
  新建一个 config.json，把 "port" 改成 18601 等数字后重新启动。
  （可参考同目录的 config.example.json）


三、数据在哪里
------------------------------------------------------------
  数据库：data\cell_data.db      ← 备份这个文件 = 备份全部数据
  备份：  backups\
  日志：  data\celltracker.log

  换电脑时，把整个文件夹（至少 data 目录）拷过去即可。


四、局域网共享（可选）
------------------------------------------------------------
  1. 新建 config.json，把 "host" 改为 "0.0.0.0"
  2. 建议同时把 auth.enabled 改为 true，并设置自己的密码
  3. 在 Windows 防火墙放行 TCP 端口 18600
  4. 其他设备访问 http://你的IP:18600/

  注意：不开启的话，程序只允许本机访问，数据不会离开这台电脑。


五、关闭程序
------------------------------------------------------------
  * 在网页左下角点「退出程序」，确认后自动关闭
  * 或直接关闭黑色命令行窗口
  * 或在窗口内按 Ctrl+C


六、更新版本
------------------------------------------------------------
  1. 下载新版压缩包，解压
  2. 只替换 CellArchive.exe
  3. 保留 data 和 backups 文件夹

  更新前建议先在网页左下角点「备份数据库」，
  把 .db 文件下载到「下载」文件夹留一份。


七、常见问题
------------------------------------------------------------
  * 页面打不开
    确认黑色命令行窗口还开着。

  * 页面空白或显示旧内容
    按 Ctrl+F5 强制刷新。

  * 想换端口
    新建 config.json，编辑 "port" 字段，保存后重新启动。

  * 想换数据库位置
    新建 config.json，编辑 "database" 字段。

  * 更多说明
    同目录下的 README.md 有完整功能说明。
