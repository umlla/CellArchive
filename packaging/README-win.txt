CellTracker 4.0.0 · 细胞培养追踪（Windows 64 位）
============================================================

一、启动
1. 把压缩包解压到有写权限的目录，例如 D:\CellTracker 或桌面。
   不要放在 C:\Program Files 下，否则程序无法创建 data 文件夹。
2. 双击 CellTracker.exe。
3. 程序会自动打开浏览器；如果没有打开，请手动访问：
   http://127.0.0.1:18600/
4. 黑色控制台窗口不要关闭，关闭就会停止服务。

二、第一次运行
- Windows 可能提示“Windows 已保护你的电脑”。
  点“更多信息” → “仍要运行”即可。
- 如果端口 18600 被占用，程序会提示；把 config.json 里的
  "port" 改成 18601 等数字后重试。

三、数据在哪里
- 数据库：data\cell_data.db
- 备份：backups\
- 日志：data\celltracker.log
- 换电脑时，把整个文件夹复制过去即可。

四、局域网共享（可选）
- 把 config.json 的 "host" 改为 "0.0.0.0"。
- 建议同时把 auth.enabled 改为 true，并设置自己的密码。
- 需要放行 Windows 防火墙的 TCP 端口 18600。

五、停止
- 关闭黑色控制台窗口，或按 Ctrl+C。

六、常见问题
- 浏览器没有自动打开：手动访问 http://127.0.0.1:18600/
- 页面空白：按 Ctrl+F5 强制刷新。
- 想换端口：编辑 config.json 的 "port"，保存后重新启动。
